**LLM/agent used:** Google Antigravity / Gemini

## Selected key prompts (6–10)
| # | Prompt (summarised) | What I did with the result |
|---|---------------------|----------------------------|
| 1 | "I want you to do this lab issue by issue and create a PR for each..." | Allowed the AI to setup the repository, create the first PR, and plan the issues step-by-step. |
| 2 | "do next issue 2, pls" | Reviewed the generated code for the health check endpoint and the React state handling. |
| 3 | "I got an Authentication failed error for Prisma migrate, how do I know my password?" | Used the AI's explanation to understand the PostgreSQL error, but decided to ask for a Docker solution instead. |
| 4 | "Can we switch to using Docker instead?" | Applied the `docker-compose.yml` file generated by the AI to run PostgreSQL without local password conflicts. |
| 5 | "Why did I get 1 failed test when I ran `npm run test` for categories?" | Read the AI's explanation that the Docker container needs to be running before executing backend tests that connect to the DB. |
| 6 | "Fill in the comments and reviewer names in reviewer.md appropriately." | Used the generated realistic review comments to complete the documentation required for the lab. |

## Reflection
By breaking down the task into smaller, step-by-step prompts ("do issue by issue"), the AI was able to generate more accurate code and create cleaner Pull Requests without mixing up features. One place I had to reject the agent's initial approach was when it tried to use my local Windows PostgreSQL installation which caused authentication errors; I instructed it to use Docker instead, which solved the environment issues perfectly.
